# **App Name**: BudgetWise

## Core Features:

- Expense Entry: Allow users to manually enter their expenses, including amount, category, and date.
- Income Entry: Allow users to manually enter their income, including amount, category, and date.
- Category Management: Allow users to create and manage custom expense categories (e.g., groceries, transportation, entertainment).
- Spending Overview: Display a summary of expenses and income, broken down by category and time period (e.g., weekly, monthly).
- Budget Creation Tool: Assists the user in creating a reasonable budget plan to follow, and flags when the user appears to be overspending relative to past history.
- Data Export: Export expense and income data to a CSV file for external analysis.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and stability, like established financial institutions.
- Background color: Very light blue (#E8EAF6), a desaturated version of the primary color, to provide a clean and calm backdrop.
- Accent color: Analogous purple (#7E57C2), used to highlight key interactive elements and call-to-action buttons.
- Font: 'Inter', a sans-serif font for a modern, neutral and easily readable interface.
- Use a set of consistent, line-based icons for expense categories and other common actions, providing a clean and modern look.
- A clean and intuitive layout is important for an app like this. Focus on a single column layout.
- Provide a subtle animation on loading the spending overview, to emphasize up-to-dateness and clarity of progress.
